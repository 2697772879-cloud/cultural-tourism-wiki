# 知识库体检（Lint）

频率：每摄取 5–10 份资料跑一次；用户问「知识库健不健康」「有没有错」时立即跑。

## 执行

```bash
PY="C:/Users/26977/.workbuddy/binaries/python/versions/3.13.12/python.exe"
"$PY" scripts/wiki_lint.py --root wiki --out wiki/lint-report.md
```

脚本输出机器可查的结构问题；**语义层面的问题需要 LLM 读页面判断**，两者都要做。

## 机器检查项

| 检查 | 说明 | 处理 |
|---|---|---|
| frontmatter 缺字段 | 必填字段缺失 | 补齐 |
| 缺视角章节 | 页面缺任一已配置视角 | 补生成 |
| 断链 | `[[X]]` 无对应页面 | 建页或改链接；批量断链说明命名不统一 |
| 孤儿页 | 无任何入链 | 补交叉引用；确实孤立的考虑合并进父页 |
| 无来源 | 事实底座里没有 `src` 锚点 | 补溯源，无法溯源的内容标记为推断或删除 |
| 疑似重复 | 标题/别名高度相似 | 人工确认后合并 |
| 索引漂移 | `index.md` 与实际页面不一致 | 跑 `wiki_index.py` 重建 |
| 未引用资料 | `raw/` 中文件未被任何页面引用 | 补建页面或说明为何不入库 |
| 长期 draft | `status: draft` 超期未复核 | 推给用户复核 |

## LLM 语义检查项

1. **矛盾**：不同页面对同一事实（年代、人名、尺寸、归属）说法不一致 → 两边保留并标 `[需人工复核]`，写入 `log.md`。
2. **过时**：新资料已修正的旧说法是否仍留在页面上。
3. **缺页**：正文中反复出现、却始终没有独立页面的重要概念/人物/建筑 → 建议建页。
4. **视角漂移**：三视角出现底座之外的事实，或三视角之间数字不一致 → 重写视角。
5. **摘要失真**：页面内容更新后，`## 摘要` 未同步。
6. **证据薄弱**：`confidence: low` 却写得言之凿凿 → 降级措辞或补证据。
7. **知识缺口**：页面里反复出现「待考」「不详」的地方，列出可从哪里补（馆方档案、地方志、口述史）。

## 报告格式

写入 `wiki/lint-report.md`：

```markdown
# 知识库体检报告

- 时间：2026-09-18 10:00
- 页面总数：42 ｜ 原始资料：87 ｜ 视角总数：126
- 结论：⚠️ 有 5 项需处理

## 必须处理
| 级别 | 问题 | 位置 | 建议 |
|---|---|---|---|
| 高 | 断链 3 处 | 钟楼.md:28、骑楼.md:12 | 建《青砖外墙》页或改为普通文本 |
| 高 | 事实冲突 | 思豪大酒店.md 第 2、5 条 | 保留两说，标复核 |

## 建议处理
- 孤儿页 4 个：风水古井、侨批……
- 缺专家视角 2 个：客房定价、1948-重建开业

## 知识缺口（LLM 判断）
- 「郭泗泉生平」仅有一句，建议补口述史或地方志
- 「修缮工艺」缺 1997 年工程的具体做法记录

## 复核队列
- [ ] 钟楼.md 事实底座第 3 条（OCR 年份）
```

## 体检后

- 把「必须处理」项逐条修完，再跑一次确认。
- 「复核队列」交给用户，不在未确认时擅自修改历史事实。
- 把本轮体检追加到 `log.md`：`## [时间] lint | 页面 42 / 问题 5`
