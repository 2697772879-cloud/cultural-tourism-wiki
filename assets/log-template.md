# 日志模板（log.md）

> append-only，只追加不修改。每条以 `## [时间] 类型 | 标题` 开头，便于 `grep "^## \[" log.md | tail -5` 解析。

## 条目类型

| 类型 | 何时写 |
|---|---|
| `ingest` | 每摄取一份原始资料 |
| `merge` | 合并进已有页面（若已在 ingest 条目里写明，可不单列） |
| `lens` | 仅重写视角 |
| `lint` | 每次体检 |
| `fix` | 人工复核后的修正 |
| `export` | 导出 / 同步到 Dify 知识库 |

## 复核标记

凡出现 `[需人工复核]` 的行，会被 lint 与人工队列抓取。写清楚**为什么**需要复核（`OCR 不确定` / `两说并存` / `缺旁证`），不要只打标记不说明。
